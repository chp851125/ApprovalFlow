# ApprovalFlow 企業簽核系統

以 ASP.NET Core MVC（.NET 10）開發的企業簽核系統，涵蓋請假、費用報銷、採購申請、加班申請四種單據。
不需要資料庫，也不需要任何付費服務或 API Key：資料以 JSON 檔儲存，前端函式庫全部放在本機（可離線使用）。

> 範例資料中的公司「微積分科技股份有限公司」、人員與供應商皆為虛構。

## 功能

| 類別 | 內容 |
|---|---|
| 單據 | 請假（依工作時段計算時數、餘額檢查）、費用（明細自動加總、單筆上限、收據）、採購（品項、預算檢查）、加班（時段與上限規則）；草稿、附件、依單別產生單號（例 `LV-202611-0001`） |
| 簽核流程 | 簽核人來源：直屬主管、部門主管、角色、指定人員、往上 N 級；單簽 / 會簽 / 或簽；依金額或天數的條件分支；核准、駁回、退回上一關、退回申請人、撤回、加簽、轉簽；修改後重新送出並保留版本；流程範本版本化（進行中單據不受新版影響） |
| 清單 | 待我簽核、已辦、我的申請、抄送給我、草稿；篩選、排序、分頁、關鍵字搜尋；低風險單別批次核准（管理員可關閉） |
| 代理 | 代理期間、適用單別；防止重疊與連鎖代理；紀錄標示「代理」 |
| 通知 | 站內通知中心（未讀紅點）；Email 以 `.eml` 寫入 `outbox/` 並有寄送紀錄；背景排程：到期提醒、逾時、自動升級至上一層主管、每日待辦摘要；每個關卡可設定時效（工作小時） |
| 管理 | 組織架構、員工帳號（停用、重設密碼、角色）、假別、費用類別、假日行事曆、系統參數、簽核流程、排程與 Email 紀錄、稽核紀錄、重設範例資料 |
| 分析 | ECharts 儀表板（管理員看全公司、其他人看個人）；報表與 Excel 匯出（ClosedXML）；稽核紀錄查詢與匯出 |
| 介面 | 繁體中文、台北時間；手機版卡片清單、底部導覽、固定在底部的簽核按鈕 |

## 執行環境

- .NET SDK 10
- Windows / macOS / Linux 皆可

## 快速開始

```powershell
dotnet run --project ApprovalFlow
```

開啟 <http://localhost:5276>。第一次啟動時，`ApprovalFlow/SeedData/*.json` 會被複製到 `ApprovalFlow/App_Data/data/`。

### 範例帳號

所有範例帳號的密碼都是 `Demo@1234`。開發環境的登入頁與頁首有「快速切換使用者」下拉選單。

| 帳號 | 身分 | 適合測試 |
|---|---|---|
| `admin` | 系統管理員 | 所有管理功能、全公司儀表板、稽核紀錄、資料維護 |
| `gm` | 總經理 | 高金額單據的最終核決 |
| `hr.lead` | 人資主管 | 員工帳號、假別、行事曆、請假 / 加班報表 |
| `fin.mgr`、`acc01` | 財務 | 費用 / 採購簽核（會簽）、費用類別、費用報表 |
| `sales.mgr` | 業務部經理 | 部門主管簽核 |
| `sales.lead1`、`sales.lead2` | 業務組長 | 直屬主管簽核、代理簽核、批次核准 |
| `sales01`～`sales06` | 業務專員 | 提出各類申請 |

## 專案結構

```
ApprovalFlow/
├─ Domain/            實體、列舉、角色與參數鍵（不依賴其他層）
├─ Application/       商業邏輯：流程引擎、表單、查詢、通知、報表；IRepository<T> 等抽象
│  ├─ Workflow/       WorkflowEngine、狀態機、範本、時效監控
│  ├─ Documents/      表單驗證、假別餘額、附件、清單查詢
│  ├─ Notifications/  通知中心、Email、每日摘要
│  └─ Reports/        儀表板、報表、稽核查詢
├─ Infrastructure/    JSON 儲存、檔案儲存、.eml 輸出、Excel 匯出、範例資料產生器
├─ Web/               Controllers、Views、篩選器、背景排程
├─ SeedData/          範例資料（進版控，每個實體一個 JSON 檔）
└─ wwwroot/lib/       Bootstrap 5、Bootstrap Icons、ECharts（本機檔案，不用 CDN）
```

## 資料與檔案

| 路徑 | 內容 | 版控 |
|---|---|---|
| `SeedData/*.json` | 範例資料 | ✔ |
| `App_Data/data/*.json` | 執行期資料 | ✘ |
| `App_Data/uploads/` | 附件 | ✘ |
| `App_Data/keys/` | 登入 Cookie 加密金鑰 | ✘ |
| `outbox/` | 模擬寄出的 `.eml` | ✘ |
| `logs/` | Serilog 日誌（每日一檔，保留 30 天） | ✘ |

### 重設範例資料

以系統管理員登入，開「資料維護」，輸入 `RESET` 後按「重設資料」。也可以停止程式，刪除 `App_Data/data` 後重新啟動。

### 重新產生範例資料（僅限 Development）

```powershell
dotnet run --project ApprovalFlow -- --generate-seed --anchor 2026-11-23
```

產生器使用固定亂數種子，同一個基準日每次產生相同內容（密碼雜湊的 salt 除外）。基準日決定範例單據的時間分布：近 12 個月的歷史單據，以及基準日當天簽核中或逾時的單據。

## 設定

`appsettings.json`：

| 區段 | 說明 |
|---|---|
| `DataStore` | 範例資料、執行期資料、附件、outbox 的路徑 |
| `DataProtection:KeysPath` | 加密金鑰存放位置 |
| `BackgroundJobs` | 背景排程開關、間隔秒數、啟動延遲 |
| `Serilog` | 日誌設定 |

業務參數在系統中的「系統參數」頁調整，例如密碼原則、登入鎖定、附件限制、批次核准、時效、每日摘要、Email。請記得把 `Site.BaseUrl` 改成實際網址，Email 裡的連結才會正確。

## 健康檢查

`GET /health`：檢查資料資料夾是否可讀寫，不需要登入。
